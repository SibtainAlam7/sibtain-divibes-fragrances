# DiVibes Fragrances — Luxury Eau de Parfum Storefront

Modern, animated luxury e-commerce storefront for **DiVibes Fragrances** built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **18 Signature 50ml Eau de Parfum Creations** (10 Men, 8 Women) with interactive filtering, mood curation, and live instant search.
- **Luxury Shopping Experience**: Editorial Quick View modal (3-slot gallery), Slide-Over Shopping Bag & Wishlist drawers (localStorage-persisted), and full Pakistan Checkout (COD, Direct Bank Transfer, Free Nationwide Delivery, WhatsApp Order Confirmation).
- **Responsive Across All Devices**: Tailored for mobile (iPhone), tablet (iPad), laptop, and desktop viewports.

## Local Development
```bash
npm install
npm run dev
```

## Production Build & Vercel Deployment
```bash
npm run build
npm run preview
```
`vercel.json` is preconfigured for React Router SPA rewrites and CDN asset caching. Push to GitHub and import directly in Vercel.
